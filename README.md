# Writing fails

A collection of accidental readings caused by writing direction or layout. Browse the gallery or [submit an example](https://github.com/mkpoli/writing-fails/issues/new?template=example.yml).

The site is static: open `index.html` or serve this directory with any HTTP server. Images are credited and linked to their sources in the gallery.
